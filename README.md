## 使用原则

1. 阅读补丁目录中的说明，先运行回归测试。
2. 应用器检查包名、版本、完整源文件 SHA-256 和精确补丁上下文；不支持的安装会拒绝修改。
3. 原文件备份位于安装目录的本地备份区，不会提交到此仓库。
4. 修改磁盘文件不会替换运行中进程已经加载的模块。暂停任务后正常重启 DSH，修复才会生效；工具不会自动重启服务。
5. 升级或重新安装 DSH 可能覆盖本地补丁。重新检查，不要强行套用旧补丁。

## 隐私边界

本仓库仅发布通用补丁、公开包版本和合成测试。不得提交真实会话、项目文件、工作区名称、用户目录、堆快照、分配采样、诊断报告、凭据或未脱敏命令输出。不要将生产诊断目录整体复制到这里。

新增补丁请使用新的编号子目录，并提供可独立运行的合成回归测试。
